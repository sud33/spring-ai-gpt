# Spring AI GPT

## Overview
Spring AI GPT is a Java-based REST API built with Spring Boot, designed to integrate with OpenAI's GPT models. It provides endpoints to interact with AI models, enabling functionalities such as generating jokes or other AI-driven responses. The project leverages Spring's web and AI starter modules to facilitate seamless communication with OpenAI's API.

## Features
- RESTful API endpoints for AI interactions
- Integration with OpenAI's GPT-4 model
- Configurable API key and model options
- Basic joke generation endpoint

## Technologies
- Java 17
- Spring Boot 3.5.5
- Spring Web
- Spring AI OpenAI Starter
- Maven for dependency management

## Setup Instructions
### Prerequisites
- Java 17 or higher
- Maven
- An OpenAI API key (set as environment variable `MYAI_GPT_KEY`)

### Clone the repository
```bash
git clone <repository_url>
cd spring-ai-gpt
```

### Configure environment variables
Set your OpenAI API key:
```bash
export MYAI_GPT_KEY=your_openai_api_key
```

### Build the project
```bash
mvn clean install
```

### Run the application
```bash
mvn spring-boot:run
```

## Usage
Once the application is running, it exposes a REST endpoint:
```
GET /one-liner-joke/{jokeType}
```
Replace `{jokeType}` with the type of joke you want, e.g., `dad`, `knock-knock`, etc.

Example:
```
curl http://localhost:8080/one-liner-joke/dad
```

The API will respond with a one-liner joke of the specified type generated by GPT.

## Configuration
- `spring.application.name`: Application name
- `spring.ai.openai.api-key`: Your OpenAI API key (set via environment variable)
- `spring.ai.openai.chat.options.model`: Model used (default: `gpt-4o-mini`)

## Testing
Run the tests with:
```bash
mvn test
```
